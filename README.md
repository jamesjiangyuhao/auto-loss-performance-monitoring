# Interactive Loss Performance Monitoring for a Simulated Personal Auto Book

## Overview

This repository contains a complete synthetic analytics application for monitoring loss performance in a simulated personal auto insurance book. The project combines data generation, metric design, reusable data processing, Plotly visualizations, and a Streamlit dashboard built for product, actuarial, underwriting, and business analytics audiences.

## Business Problem

Insurance stakeholders often need to understand where loss ratio movement is coming from, whether deterioration is concentrated in specific geographies or vehicle segments, and whether results remain stable after adjusting the premium basis. This project recreates that analytical workflow with fully synthetic data so the portfolio example can be shared publicly.

## Why This Project Matters

The application demonstrates how a repeatable analytics workflow can replace one-off reporting. It lets users slice performance by month, state, region, vehicle make/model, sales channel, business type, and catastrophe indicator, then move from headline performance to specific drivers.

## Synthetic Data Design

The dataset is generated by `src/generate_synthetic_data.py` and includes more than 50,000 monthly policy-vehicle records. It uses fictional vehicle makes and models, generic sales channels, generic business types, and simulated comprehensive claim categories.

Controlled patterns are included:

- Elevated theft experience for selected fictional vehicle models
- Weather loss spikes in synthetic catastrophe months
- Slightly worse new business performance than renewal performance
- Higher loss ratios in selected states
- A distinct risk mix for the Partner channel

## Key Metrics

- Loss ratio: incurred loss divided by selected premium basis
- Claim frequency: claim count divided by exposure units
- Severity: incurred loss divided by claim count
- Earned premium and on-level premium
- Claim mix by loss category
- Credibility-filtered segment performance

## Analytical Workflow

1. Generate deterministic synthetic policy, exposure, premium, and claim records.
2. Apply user-selected filters for geography, time period, vehicle, channel, business type, and catastrophe treatment.
3. Aggregate to monthly, state, channel, business type, and vehicle segment views.
4. Calculate loss ratio, claim frequency, and severity.
5. Apply credibility thresholds to reduce small-sample noise.
6. Translate the results into dashboard visuals and short business insights.

## How to Run

```bash
pip install -r requirements.txt
python src/generate_synthetic_data.py
streamlit run app.py
```

The app also generates the synthetic dataset automatically if `data/synthetic_auto_claims.csv` is missing.

## Example Insights

- Certain fictional vehicle make/model combinations show elevated theft-driven loss ratios after credibility filtering.
- Synthetic catastrophe months create visible weather loss spikes in selected states.
- New business generally performs worse than renewal business on loss ratio.
- Channel-level claim frequency varies because the synthetic risk mix differs by sales channel.
- On-level premium can change period comparisons by placing premium on a more comparable basis.
